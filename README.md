# Lilith Reader

[![PR CI](https://github.com/ACSProgram/Lilith-Reader/actions/workflows/pr.yml/badge.svg)](https://github.com/ACSProgram/Lilith-Reader/actions/workflows/pr.yml)

Windows 上的桌面文档阅读器，从 [Lilith](F:\programs\Lilith) 主项目分离出来的独立应用。
单个 exe，静态链接，除 Windows 系统组件外不依赖任何运行时，复制到任意目录即可运行。

文档解析用 MuPDF，界面用 ImGui + Direct3D 11 自绘，页面画布自研。关注点是阅读本身：
翻页跟手、放大不模糊、记住读到哪里、界面不喧哗。

## 功能

### 文档

- 支持 PDF、EPUB、MOBI、FB2、CBZ、XPS 与常见图片格式（png/jpg/jpeg/gif/bmp/tif/tiff，
  图片按单页文档打开；`.webp` 无对应解码器，暂不支持）
- `LilithReader.exe <文件路径>` 直接打开，也可关联为打开方式后双击
- 在**支持格式内按内容**识别：扩展名决定文件是否送入打开流程，送入后能认出是什么就按什么
  打开，扩展名不符只作提示（epub 改名 `.pdf` 仍按 epub 阅读）。唯一例外是**压缩包冒充单文档**
  —— zip 图集改名成 `.epub`/`.pdf` 会被拒绝，因为处理器会按压缩包里的图片条目凭空编出页数
- 加密 PDF 弹密码框（RC4 40/128、AES-128、AES-256），证书/PKI 与第三方 DRM 不支持

### 阅读

- 连续滚动、1~4 列网格、双页对开（书籍模式）、旋转 0/90/180/270°
- 按缩放级别重新渲染：缩放时先显示旧纹理，高清渲染完成后换入，不闪白、放大不模糊
- 逐页按**真实尺寸**排版，同一文档内页面大小不一致也不会被拉伸变形
- 记忆每本书的阅读位置、缩放、列数、旋转、对开与纸张方案；书签随文档保存
- 记录的身份用**内容指纹**（头中尾稀疏采样）而不是路径，文件移动、复制、重新下载都不丢
- 目录（PDF outline）、书签、缩略图侧栏，点击跳转

### 外观

- **纸张方案**：原色 / 深色纸张 / 暖色。只重映射纸面与文字，页面里的照片与插图保持原色；
  整页扫描件则整体变换
- **界面主题**：浅色 / 深色 / 跟随系统。与纸张方案是两个独立维度，互不覆盖
- 界面随显示器 DPI 缩放，高 DPI 下不发糊

### 界面与操作

- 顶栏图标按钮 + 主菜单 + 画布右键菜单；命令收在菜单里，不往工具栏堆按钮
- 设置窗口五栏：界面 / 阅读 / 性能 / **按键** / 阅读数据，改动即时生效并落盘
- **按键可自定义**：命令表每条命令两个键槽，可改键、清除、恢复默认；滚轮缩放的修饰键也可改。
  改不了的鼠标操作列在同一分栏末尾的「鼠标与固定键」清单里
- 动效：缩放插值、滚动平滑、跳页滑行、顶栏自动隐藏滑出/滑入、侧栏滑入滑出、页面淡入、
  弹窗淡入淡出；由「设置 → 界面 → 动效」统一开关，关闭即全部直切
- 全屏（`F11`）、可拖拽的滚动条（拖拽 / 点轨道跳转 / 悬停加宽）

### 文本与检索

- **文本选择与复制**（`Ctrl+C` / 右键「复制」）：需要文档有文字层，**不做 OCR**，
  纯扫描件与矢量公式选不中
- **复制嵌入图片**：右键点页面上的插图，按原始分辨率写入剪贴板
- **超链接**：悬停手型光标，外部链接用系统浏览器打开，文档内链接直接翻页
- **全文搜索**（`Ctrl+F`）：输入停手约 0.4 秒自动检索，可取消；结果列在侧栏「搜索」分栏，
  带命中行上下文，画布上高亮命中并强调当前项

### 数据与诊断

- 便携：设置写 exe 同目录 `LilithReader.ini`，阅读进度写 `reader_state.bin`（原子写入），
  整个目录拷走就带着全部数据
- 「设置 → 阅读数据」可查看存了哪些文档，支持单条删除、清空、清理位置未知的旧记录
- 崩溃转储写 exe 同目录 `crash\`，下次启动提示并可一键打开；运行日志写 `logs\`（单文件 2 MiB 轮转）

## 快捷键（默认）

| 键 | 作用 |
|---|---|
| `O` / `B` | 侧栏 / 当前页书签 |
| `R` / `D` | 旋转 90° / 双页对开 |
| `I` / `E` | 深色纸张 / 暖色纸张 |
| `1`~`4` | 列数（切换列数会退出对开） |
| `F` / `Ctrl+0` / `+` `-` | 适应宽度 / 缩放 |
| `←` `→` `↑` `↓` `PgUp` `PgDn` `Home` `End` | 翻页与滚动 |
| `G` / `Ctrl+O` | 跳页 / 打开文档 |
| `Ctrl+,` / `F1` | 设置 / 按键设置 |
| `Ctrl+C` / `Ctrl+A` / `Ctrl+F` | 复制选中 / 全选本页文字 / 查找 |
| `F11` / `Esc` | 全屏开关 / 关闭当前对话框 |
| `Shift+F10` / 菜单键 | 画布右键菜单 |

鼠标：滚轮滚动；按住 `Ctrl` 滚轮以鼠标为中心缩放（修饰键可改）；左键拖拽平移（在文字上则是
选择文本）；中键拖拽平移；右键菜单；拖拽右侧滚动条。全部键盘命令可在「设置 → 按键」中修改。
阅读态的快捷键不依赖窗口焦点，也不受输入法干扰。

## 架构

分六层，依赖自上而下单向：

```
┌──────────────────────────────────────────┐
│ app       界面与交互：窗口、菜单、设置、绘制      │
├──────────────────────────────────────────┤
│ canvas    页面布局：缩放、平移、多列、滚动        │
├──────────────────────────────────────────┤
│ render    渲染调度：后台渲染、缓存、纹理管理      │
├──────────────────────────────────────────┤
│ document  解析文档（MuPDF 封装）                │
├──────────────────────────────────────────┤
│ state     阅读进度与书签的持久化                │
├──────────────────────────────────────────┤
│ utils     路径、编码、配置读写                   │
└──────────────────────────────────────────┘
```

三条约束决定了这套划分：

1. **界面线程不做慢操作**：打开文档、渲染页面、抽取文本全在后台工作线程完成，
   界面线程只投递请求与读取快照，不碰 MuPDF，也不在交互路径上等磁盘
   （阅读进度由独立线程落盘，仅退出时做一次同步收尾）。
2. **布局是纯计算**：页面摆在哪、怎么缩放是不依赖界面的纯函数，因此能写成自动化测试。
3. **解析层可替换**：`document` 对外只暴露与 MuPDF 无关的类型，若要换底层引擎只改这一层。

技术栈：C++20（大量使用 C++20 modules）、ImGui + Direct3D 11 自绘界面、MuPDF 静态链接、
vcpkg 管理依赖、`/MT` 静态 CRT。

## 构建

- Visual Studio 18 (2026) Community（PlatformToolset v145）+ vcpkg（manifest 模式，`x64-windows-static`）
- 打开 `LilithReader.slnx` 按 F5，或命令行运行 `build.bat`；依赖由 vcpkg 自动安装
- 产物 `bin\Release\LilithReader.exe`，约 38 MiB，其中约 30 MiB 是 MuPDF 内置兜底字体
  （中文文档未内嵌字体时必需），约 1 MiB 是内嵌的界面字体子集。构成与裁剪手段见
  [体积预算](docs/05-体积预算.md)
- 环境细节（依赖安装位置、overlay ports、已知的 MSBuild 环境坑）见
  [架构设计 §8](docs/02-架构设计.md)

## 安装

发布形态是 Inno Setup 安装包：

```
installer\build_installer.bat        :: 需 Inno Setup 6；先跑过 build.bat
→ installer\dist\LilithReader-<版本>-setup.exe
```

- **每用户安装**，装到 `%LOCALAPPDATA%\Programs\Lilith Reader`，不需要管理员权限
  （程序把数据写在 exe 同目录，装进 `Program Files` 会因权限不足静默失效）
- 文件关联在向导里勾选（文档格式默认全勾、图片默认不勾），全部写 HKCU，卸载时精确回收
- **升级为就地覆盖**：沿用上次的安装目录与勾选，阅读数据原样保留
- 卸载时会询问是否保留阅读数据，默认保留

## 已知问题

- **最大化状态下退出全屏有一次可见抖动**：窗口先向左上收缩一下再归位。普通窗口无此现象。
  已排除帧内命令时机、Win32 调用顺序、swapchain 重建时机三个方向，剩余疑点在
  `SetWindowPlacement(SW_SHOWMAXIMIZED)` 的内部中间态。
- **Windows Defender 可能误报**：未签名 + 静态链接的 exe 容易被启发式引擎误判。
  本机把 `bin\` 加入排除项，或[向微软上报误报](https://www.microsoft.com/en-us/wdsi/filesubmission)；
  彻底解决需要代码签名证书。
- **不做 OCR**：纯扫描件没有文字层，既选不中也搜不到。
- **MOBI 只支持未压缩与 PalmDOC 两种压缩**：Kindle 生成的 MOBI 多用 HUFF/CDIC 压缩，
  MuPDF 没有实现这条路径，这类 `.mobi` 会提示"暂不支持的格式"（其余 MOBI 正常打开）。
- **文本选择限单页**：拖到页边之外时选区止于本页。
- **公式与矢量内容复制不全**：画成矢量路径或位图的内容没有文字层；字体缺少 `ToUnicode`
  映射时能选中但复制会缺字；公式的上下标由多个文本对象拼成，复制按阅读顺序拼接，
  可能与视觉顺序不同。均属 PDF 文本提取的固有限制。
- **界面字体是内嵌子集 + 系统兜底**：界面自述文字 100% 覆盖，但文件名、PDF 目录标题这类
  文档侧的生僻字依赖系统 `msyh.ttc`，系统缺该字体时显示缺字框。
- **加密文档声明"禁复制"时不强制限制**：权限位（`can_copy`）已读取，但产品决定不据此禁用
  复制（保持放行）；如需严格尊重 PDF 权限位可另行讨论。
- **搜索有 0.4 秒防抖**：打完字停手约半秒才开始检索，刻意如此 —— 逐字符检索会占满后台线程。
