# Lilith Reader

![PR CI](https://github.com/ACSProgram/Lilith-Reader/actions/workflows/pr.yml/badge.svg)

Windows 上的桌面文档阅读器，从 Lilith 主项目分离出来的独立应用。  
整个程序只有一个 exe 文件，运行需要的组件都已打包在内，复制到任意目录即可使用。

程序是原生 Windows 程序，启动和翻页都尽量做到轻快。

预编译的安装包见 [Releases](https://github.com/ACSProgram/Lilith-Reader/releases)  
（Windows 10 1809 及以上，64 位）。

## 功能

### 文档

- 支持 PDF、EPUB、MOBI、FB2、CBZ、XPS 与常见图片格式（png/jpg/jpeg/gif/bmp/tif/tiff，  
  图片按单页文档打开；`.webp` 暂不支持）
- 直接运行 `LilithReader.exe` 打开文件，也可以在系统里把它设为这些格式的默认打开方式，  
  之后双击文件即可阅读
- 打开时按**文件的实际内容**判断格式，不只看扩展名：把 epub 改名成 `.pdf` 仍会按 epub 阅读，  
  扩展名对不上只会给个提示。唯一的例外是把图片压缩包改名成 `.epub`/`.pdf`，这类会被拒绝打开
- 加密 PDF 会弹出密码输入框；用证书或第三方版权保护（DRM）加密的文档不支持

### 阅读

- 连续滚动、1~4 列网格、双页对开（书籍模式）、旋转 0/90/180/270°
- 缩放时先放大当前画面顶着，清晰版渲染好后再换上，不闪白、放大不模糊
- 逐页按**真实尺寸**排版，同一文档里页面大小不一致也不会被拉伸变形
- 记住每本书的阅读位置、缩放、列数、旋转、对开与纸张方案；书签随文档保存
- 靠**文件内容**认书而不是靠路径：文件改名、移动、复制或重新下载，都能接着上次的位置继续读
- 目录、书签、缩略图侧栏，点击即可跳转

### 外观

- **纸张方案**：原色 / 深色纸张 / 暖色。只调整纸面和文字的颜色，页面里的照片与插图保持原样；  
  整页扫描的图片则整体变暗或变暖
- **界面主题**：浅色 / 深色 / 跟随系统。界面和纸张的颜色可以分别设置，互不影响
- 界面随显示器的缩放比例自动放大，高分屏下不发糊

### 界面与操作

- 顶栏图标按钮 + 主菜单 + 画布右键菜单；命令都收在菜单里，不在工具栏堆按钮
- 设置窗口四栏：界面 / 性能 / **按键** / 阅读数据，改动即时生效并保存
- **按键可自定义**：每个功能可以设两个快捷键，支持改键、清除、恢复默认；`Ctrl` 这类组合键也能改。  
  鼠标操作等无法自定义的项目，列在同一栏末尾的说明里
- 动效：缩放平滑、滚动平滑、跳页滑行、顶栏自动隐藏滑出/滑入、侧栏滑入滑出、页面淡入、  
  弹窗淡入淡出、全屏底栏弹出；由「设置 → 界面 → 动效」统一开关，关闭即全部直切
- 全屏（`F11`）、可拖拽的滚动条（拖拽 / 点轨道跳转 / 悬停加宽）。进出全屏时页面会重新排版，  
  程序以当前画面中心的内容为基准，页码和正在看的内容不会跑掉
- **自动隐藏的栏浮在页面之上**：顶栏（阅读态开着「顶栏自动隐藏」时）与全屏时的底栏都盖在  
  页面上方，滑入/滑出不会挤动页面；全屏底栏默认收起，鼠标移到窗口底端才滑出

### 文本与检索

- **选中并复制文字**（`Ctrl+C` 或右键「复制」）：需要文档本身带有可选的文字。扫描件和  
  画出来的公式选不中，本程序不做文字识别（OCR）
- **复制图片**：右键点页面上的插图，按原图大小复制到剪贴板
- **超链接**：悬停时变手型光标，外部链接用系统浏览器打开，文档内链接直接翻页
- **全文搜索**（`Ctrl+F`）：输入停手约 0.4 秒自动开始，可随时取消；结果列在侧栏「搜索」分栏，  
  每条显示匹配到的那行文字，页面上高亮所有匹配位置

### 导出

- **把页面导出为图片**（主菜单「导出为」，或 `Ctrl+E`）：PNG（无损）或 JPEG（有损、质量可调）  
- 范围可选当前页 / 全部页 / 自定义；清晰度（DPI）可调到 72~1200，越高越清晰、文件也越大；  
  单页导出一个文件，多页则按 `<文档名>_p0001.png` 这样一页一个文件写进所选文件夹
- 默认导出文档**本来的样子**；勾选「应用当前视图」则连同当前的旋转与纸张配色一起导出，  
  所见即所得

### 数据与诊断

- 便携：设置和阅读进度都存在程序目录里，把整个目录拷走就带着全部数据
- 「设置 → 阅读数据」可查看存了哪些文档，支持单条删除、清空，以及清理认不出文档的旧记录
- 崩溃时会在程序目录的 `crash\` 里留下报告，下次启动会提示并可一键打开；  
  运行日志写在 `logs\`，单个文件不超过 2 MiB

| `Ctrl+,` / `F1`                            | 设置 / 按键设置          |
| `Ctrl+C` / `Ctrl+A` / `Ctrl+F`             | 复制选中 / 全选本页文字 / 查找 |

| `F11` / `Esc`                              | 全屏开关 / 关闭当前对话框     |

鼠标：滚轮滚动；按住 `Ctrl` 滚轮以鼠标位置为中心缩放（这个组合键可以改）；左键拖拽平移（在

中修改。阅读态的快捷键不依赖窗口焦点，也不受输入法干扰。

## 架构

分六层，依赖自上而下单向：

```
┌──────────────────────────────────────────┐
│ app       界面与交互：窗口、菜单、设置、绘制      │
├──────────────────────────────────────────┤
│ canvas    页面布局：缩放、平移、多列、滚动        │
├──────────────────────────────────────────┤
│ render    渲染调度：后台渲染、缓存、纹理管理      │
├──────────────────────────────────────────┤
│ document  解析文档（MuPDF 封装）                │
├──────────────────────────────────────────┤
│ state     阅读进度与书签的持久化                │
├──────────────────────────────────────────┤
│ utils     路径、编码、配置读写                   │
└──────────────────────────────────────────┘
```

三条约束决定了这套划分：

1. **界面线程不做慢操作**：打开文档、渲染页面、抽取文本全在后台工作线程完成，  
   界面线程只投递请求与读取快照，不碰 MuPDF，也不在交互路径上等磁盘  
   （阅读进度由独立线程落盘，进程内每 2 秒按需保存一次，退出时再做一次同步收尾）。
2. **布局是纯计算**：页面摆在哪、怎么缩放是不依赖界面的纯函数，因此能写成自动化测试。
3. **解析层可替换**：`document` 对外只暴露与 MuPDF 无关的类型，若要换底层引擎只改这一层。

技术栈：C++20（大量使用 C++20 modules）、ImGui + Direct3D 11 自绘界面、MuPDF 静态链接、  
vcpkg 管理依赖、`/MT` 静态 CRT。

## 构建

- Visual Studio 18 (2026) Community（PlatformToolset v145）+ vcpkg（manifest 模式，`x64-windows-static`）
- 打开 `LilithReader.slnx` 按 F5，或命令行运行 `build.bat`；依赖由 vcpkg 自动安装
- 产物 `bin\Release\LilithReader.exe`，约 38 MiB，其中约 30 MiB 是 MuPDF 内置兜底字体  
  （中文文档未内嵌字体时必需），约 1 MiB 是内嵌的界面字体子集。构成与裁剪手段见  
  [体积预算](docs/05-体积预算.md)
- 环境细节（依赖安装位置、overlay ports、已知的 MSBuild 环境坑）见  
  [架构设计 §8](docs/02-架构设计.md)

## 安装

发布形态是 Inno Setup 安装包。从 [Releases](https://github.com/ACSProgram/Lilith-Reader/releases)  
下载安装，或自行打包（需 Inno Setup 6，且先跑过 `build.bat`）：

```
installer\build_installer.bat
→ installer\dist\LilithReader-<版本>-setup.exe
```

- **每用户安装**，装到 `%LOCALAPPDATA%\Programs\Lilith Reader`，不需要管理员权限  
  （程序把数据写在 exe 同目录，装进 `Program Files` 会因权限不足静默失效）
- 文件关联在向导里勾选（文档格式默认全勾、图片默认不勾），只写当前用户，卸载时精确回收
- **升级为就地覆盖**：沿用上次的安装目录与勾选，阅读数据原样保留
- 卸载时会询问是否保留阅读数据，默认保留
- 安装包**未做代码签名**，Windows 可能提示"发布者未知"或弹出 SmartScreen 拦截，选择继续运行即可

## 已知问题

- **不做文字识别（OCR）**：纯扫描件没有可选的文字，既选不中也搜不到。
- **MOBI 只支持部分压缩方式**：Kindle 生成的 MOBI 常用一种本程序尚未实现的压缩方式，  
  这类 `.mobi` 会提示"暂不支持的格式"，其余 MOBI 正常打开。
- **文字选择限于当前页**：拖到页面之外时，选区止于本页。
- **公式与图形内容的复制不完整**：画成图形或图片的内容没有文字层；字体本身缺少字符对照信息  
  时能选中但复制会缺字；公式的上下标由多段文字拼成，复制时按阅读顺序拼接，可能与视觉顺序  
  不同。这些都是 PDF 文字提取本身的限制。
- **界面字体是内嵌子集加系统字体兜底**：界面自己的文字全部覆盖，但文件名、PDF 目录标题里的  
  生僻字依赖系统字体，系统缺少时会出现缺字框。
- **加密文档声明"禁止复制"时不强制限制**：程序读到了这个权限标志，但选择不据此禁用复制；  
  如需严格遵从 PDF 权限设置可另行讨论。
- **搜索有 0.4 秒延迟**：打完字停手约半秒才开始搜索，这是有意为之 —— 每敲一个字就搜全文会  
  一直占着后台，影响翻页流畅。
