## 1. 总体结构

```
┌────────────────────────────────────────────────────┐
│ src/app        入口 / Win32 / D3D11+ImGui / 命令行  │
├────────────────────────────────────────────────────┤
│ src/canvas     自研画布：布局·缩放·平移·滚动·网格    │
├────────────────────────────────────────────────────┤
│ src/render     渲染调度：线程池·LRU字节预算·纹理池   │
├────────────────────────────────────────────────────┤
│ src/document   MuPDF 封装：Document·页面·密码·目录  │
├────────────────────────────────────────────────────┤
│ src/utils      路径/字符串/日志/崩溃转储            │
└────────────────────────────────────────────────────┘
```

依赖方向自上而下单向；`document` 与 `canvas` 互不 import，通过 `render` 调度层衔接——这是为将来替换 MuPDF 为 PDFium 预留的解耦（ADR-003）。

## 2. 自研画布设计

### 2.1 视图状态（唯一真源）

```
struct CanvasState {
    float   zoom;            // 每点屏幕像素（fit_width 时该值被派生值覆盖）
    float   scroll_x;        // 内容坐标（px）水平偏移
    float   scroll_y;        // 内容坐标（px）垂直偏移
    int     columns;         // 1~4 列
    bool    fit_width;       // fit-width 模式时 zoom 派生
    float   margin_px;       // 四周留白（屏幕像素）
    float   gap_px;          // 页间/列间间距（屏幕像素）
};
```

页面布局是**纯函数**：`page_rect(index, state) → 屏幕矩形`。任何输入（滚轮/拖拽/键盘）只修改 state，渲染每帧按 state 重算布局。无隐藏状态、无 Invalidate 区域管理，天然可预测。

**坐标模型（ADR-018）**：文档内部以**点（pt）**为单位，`zoom` = 每点屏幕像素
（`zoom = 1.0` 即 72dpi）。`margin_px`/`gap_px` 为**屏幕像素**常量，换算进文档坐标时
除以 zoom，故缩放时页间距视觉恒定。`fit_width` 派生
`zoom = (viewport_w − 2·margin_px − (cols−1)·gap_px) / (cols · max_page_w_pt)`，
使内容宽度恰等于视口宽。内容窄/矮于视口时居中，否则按 scroll 偏移并钳制到
`[0, content − viewport]`。派生量（内容尺寸、行顶前缀和）做可失效缓存，滚动不使其失效。

> 本期所有页面按**统一尺寸**布局（取首页尺寸）；异构尺寸页的逐页布局留待后续，
> 接口 `set_page_sizes` 已就位。

### 2.2 输入映射

| 输入 | 行为 |
|---|---|
| 滚轮 | 垂直滚动 |
| Ctrl+滚轮 | 以**鼠标位置为不动点**缩放 |
| 左键拖拽 | 平移 |
| ←→ | 上一行 / 下一行（单列即上/下页） |
| ↑↓ / PgUp PgDn | 小步 / 整屏滚动 |
| Home / End | 首页 / 末页 |
| G | 跳页输入框 |
| 1~4 | 列数 |
| F / Ctrl+0 | 回到 fit-width |
| +/− | 以视口中心缩放 |
| F11 | 全屏 |

（平滑插值/惯性滚动属 Phase 6 微动效，本期为直接滚动。）

### 2.3 渲染请求协议（画布 → 调度层）

画布每帧输出 `std::vector<RenderWant>{ page, scale }`（可见页 + 预加载页及其**目标倍率**，
可见页优先）。调度层负责去重、排队、换入。画布不感知线程，只读
`PageSlot{ PageStatus, void* texture, pixel_w/h, scale }`——`texture` 是**不透明句柄**
（`ID3D11ShaderResourceView*`），画布只读、绝不持有所有权（ADR-019）。

### 2.4 缩放清晰度策略

- 每页**一份**当前纹理；缩放变化 → **150ms 防抖** → 以新倍率请求渲染 → 完成后
  替换该页纹理，旧纹理入退役队列（ADR-019）
- 防抖期间用现有纹理**双线性放大**显示（不闪白、不错位）
- 单页渲染尺寸上限钳制（默认 8192px），超大页面（A0/长图 PDF）预留 tile 分块接口
- 倍率与已投递倍率一致时**不重渲**；渲染请求按 (页, 倍率) 去重（ADR-020）

## 3. 渲染调度与稳定性

### 3.1 线程模型

- UI 线程：ImGui 帧循环 + 画布布局，**零阻塞调用**（绝不碰 fz_* 与磁盘）
- 渲染线程：Phase 2 起采用**单线程串行**——`Document` 实例归属唯一工作线程，
  UI 线程只投递请求、读取快照（ADR-012）。阅读器单线程渲染已足够流畅，
  且彻底规避共享 `fz_document` 的并发风险。Phase 3 起该线程由 `lilithreader.render`
  的 `Renderer` 持有（取代 Phase 2 的临时 `DocSession`，ADR-020）。
- 若将来确有并发渲染需求，再启用 ADR-006 预留的第二条路（每线程 `fz_clone_context`，
  共享 `fz_document`）；本期不实现，接口（`DocError` / `PageBitmap`）无需改动。
- 像素上传：渲染线程用 `ID3D11Device` 直接建纹理（`CreateTexture2D` + 初始数据，
  `IMMUTABLE`；device 方法 free-threaded，无需延迟上下文），上传完成即释放
  `PageBitmap`（ADR-019）

### 3.2 页状态机

```
Unloaded → Loading → Loaded
                  ↘ Failed（错误占位 + 点击重试，自动重试 ≤ 1 次）
```

修复 Lilith 版缺陷：渲染任务异常后 status 永远停留 Loading（白屏）。

### 3.3 缓存与生命周期

- 纹理删除经过**退役队列**：渲染线程把被替换/逐出的纹理入队，UI 线程**帧首**
  `drain_retired()` 统一释放——杜绝悬空 GPU 句柄（ADR-019）
- Phase 3 缓存策略为**保留窗口**（可见 ± 预加载，外扩 4 页）：窗口外的已加载页被逐出；
  **Phase 4** 改为按**字节预算**的 LRU（默认 512MB，可调 128MB~2GB），本层接口不变
- 预加载为可见行 ±1 行；方向感知（向下滚动只预加载下方）属 Phase 4

### 3.4 崩溃防线（分层）

1. **模块边界**：`document` 层所有 fz_* 调用 `fz_try/catch` 全覆盖，错误以返回值/结构化错误码出边界
2. **帧边界**：每页绘制独立 try/catch（TryInvoke 模式），单页异常不影响进程
3. **进程边界**：`set_terminate` + SEH 顶层 → MiniDump 写 exe 同目录 `crash/`，下次启动提示
4. **输入边界**：损坏文件 fuzz 集（空/截断/假后缀/加密）全部优雅报错（Phase 2 验收项）

### 3.5 加密 PDF

- 支持标准安全 handler 全系（RC4 40/128、AES-128、AES-256 R6）
- `fz_open_document` 密码错误 → UI 密码框 → `fz_authenticate_password`，权限位掩码读取并在 UI 层尊重（如禁用复制）；证书/PKI 与第三方 DRM 不支持，按损坏处理

## 4. 字体方案

- UI 文字全部由 ImGui + imgui_freetype 内存栅格化，**字体 `#embed` 进 exe**
- 主字体：中文字体子集（常用 3500 汉字 + Latin + 标点，`pyftsubset` 生成，约 1.5~2MB），候选：思源黑体 / 霞鹜文楷（后者阅读器气质更好）
- Fallback：可选运行时加载 `C:\Windows\Fonts\msyh.ttc` 补生僻字（缺失也不影响完整性）
- PDF 页内文字由 MuPDF 用文档自带字体渲染，与 UI 字体无关

## 5. 持久化

- `reader_state.bin`（exe 同目录）：窗口状态、每文档阅读位置（键 = 文件路径 + 大小 + 修改时间哈希）、书签
- 全部写入为「临时文件 + 原子替换」，杜绝写坏配置
