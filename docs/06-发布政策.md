# 发布政策

> 本文件是**版本与发布口径的唯一出处**：版本号写在哪、切版本要动哪些地方、CI 与人工门槛是什么。
> 借鉴同级项目「发行政策」（滞后版本号、自动门槛 + 人工门槛）的做法，按本项目形态
> （C++ / Inno Setup / 单一 exe / 两级 CI）裁剪。
>
> 进行中的批次见[计划](01-计划.md)；体积构成与实测见[体积预算](05-体积预算.md)；
> 构建与 CI 的技术细节见[架构设计 §8](02-架构设计.md)。

## 1. 版本号口径

- 版本使用**语义化版本**。预发布阶段带 `-rc.N` 后缀（当前 `1.0-rc.2`），正式版去掉后缀。
- **显示版本**（可含预发布后缀，如 `1.0-rc.2`）用于：安装包文件名、注册表显示、欢迎页文案、
  exe 版本资源字符串、`SECURITY.md`、CHANGELOG 小节标题。
- **数字版本**是 PE 版本资源的 4 段纯数字（`1.0.0.0`），**无法承载预发布后缀**。预发布阶段
  数字版本与显示版本的首个数值段对齐即可（`1.0-rc.N` ↔ `1.0.0.0`）；**各 rc 之间数字版本可以
  相同**——PE 层面靠字符串版本区分，这是刻意的取舍而非疏漏。
- 数字版本由 `installer/LilithReader.iss` 的 `MyAppVersionNumeric` 与 `src/app/app.rc` 的
  `FILEVERSION` **编译期绑定**：两者不一致时安装器直接编译失败，杜绝"安装包说 rc.2、程序说
  rc.1"这类漂移（见[架构设计 §8.2](02-架构设计.md)）。

## 2. 版本号的权威位置（切版本须同步）

| 位置 | 字段 | 形式 |
|---|---|---|
| `installer/LilithReader.iss` | `MyAppVersion` | 显示版本，如 `1.0-rc.2` |
| `installer/LilithReader.iss` | `MyAppVersionNumeric` | 数字版本，如 `1.0.0.0` |
| `src/app/app.rc` | `FILEVERSION` / `PRODUCTVERSION` | 数字版本 `1,0,0,0` |
| `src/app/app.rc` | `FileVersion` / `ProductVersion`（字符串） | 显示版本 `1.0-rc.2` |
| `vcpkg.json` | `version-string` | 工程版本，如 `1.0.0-rc.2` |
| `SECURITY.md` | 「当前开发版本」 | 显示版本 `1.0-rc.2` |
| `CHANGELOG.md` | 版本小节标题 | `## <显示版本> — YYYY-MM-DD` |
| `docs/02-架构设计.md`、`docs/05-体积预算.md` | 示例串 / 实测文件名的版本标注 | 随实测更新 |

> **体积类数字只在重新打包实测后更新**，不随版本号同步凭空改写；旧实测值保留并标注其版本
> （如 `1.0-rc.1 打包实测`）。

## 3. 切版本的固定动作

1. `CHANGELOG.md`：把当前版本小节落日期并冻结为 `## <显示版本> — YYYY-MM-DD`；此后新改动进入
   下一小节（尚未切版本前，可先记在版本小节里并注明"开发中"）。
2. 同步 §2 表中除体积外的全部字段。
3. 本地编译（`build.bat`）与 `tests\run_tests.ps1` 全绿——切版本不改代码，但不留未经编译验证的提交。
4. 提交；**是否打标签、是否推送由维护者单独决定**——切版本 ≠ 发布。

## 4. 打标签与发布

- 候选版标签 `v<显示版本>`（如 `v1.0-rc.2`）。标签一旦推送即**公开**，不可复用或替换；标签之后
  任何代码、资源或版本串变化都必须切到新版本并打新标签。
- 推送 `v*` 标签触发**发布级 CI**（`.github/workflows/release.yml`）：构建 → **校验 tag 与版本串
  一致** → 跑一次全量回归 → 打安装包 + 体积门禁 → 生成 `SHA256SUMS.txt` → 用 CHANGELOG 本版小节
  作说明创建**草稿**预发布。草稿由维护者复核安装包与说明后**手动**发布，CI 不自动公开。

## 5. 门槛

**自动门槛（两级 CI，见[架构设计 §8.3](02-架构设计.md) / ADR-102）**

- 验证级 `pr.yml`：Debug/Release 构建 + Release 全量回归 + 安装包构建与体积门禁（≤ 35 MiB）。
- 发布级 `release.yml`：tag 与版本一致性 + 全量回归 + 安装包体积门禁 + SHA-256 校验和。

**人工门槛**（候选版公开发布前，在干净 Windows 用户环境完成一次桌面验收）

- 安装（普通用户账户）、首次启动、打开文档、关闭与显式退出；
- 阅读：翻页 / 缩放 / 列数 / 对开 / 旋转 / 纸张方案 / 设置与阅读位置持久化；
- 文本与检索：选择复制 / 图片复制 / 超链接 / 全文搜索；
- 导出为图片：对话框与输出选择、结果与文件名、导出期间阅读不受影响与取消；
- 从上一公开版本**就地覆盖升级**、卸载时数据去留；
- 未签名安装包的 SmartScreen / "发布者未知"提示**已知且属预期**（见根 README「安装」）。

人工结果写入[人工验证](04-人工验证.md)的台账，通过后整节归档；**本文件只定门槛，不记结果**。
