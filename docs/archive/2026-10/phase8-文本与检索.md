> 与 [决策记录](../../03-决策记录.md) ADR-069~071。

## 实施内容

- **坐标空间统一为"未旋转页面 pt"**：旋转折算抽成纯函数 `src/app/page_map.h`，
  旋转视图下整套命中测试与高亮**零分支**（ADR-069）
- **文本选择与复制**：悬停文本 → I 型光标、此时左键拖拽即选择（平移让位，另有中键拖拽兜底）；
  选区限单页；复制走 `fz_copy_selection`（按阅读顺序拼接、自动补词间空格）；`Ctrl+C` / 右键「复制」
- **嵌入图片复制**：右键位置命中 `stext` 的 IMAGE 块 → `fz_get_pixmap_from_image` 取原图
  → 写 `CF_DIB`（32bpp BGRA、alpha 恒 255）；无图时该项置灰
- **超链接**：外部 URL 走 `ShellExecuteW`（系统浏览器），文档内跳转复用 `request_jump_scroll`；
  悬停手型光标 + 淡色底；右键另有「复制链接」
- **全文搜索**：分页增量（每轮 24 页）+ 可取消 + 渐进发布；两级命中上限（单页 200 / 全局 5000）；
  侧栏第 4 分栏「搜索」（`Ctrl+F` 直达），结果带命中行上下文，画布上高亮命中并强调当前项
- **剪贴板**：文本 `CF_UNICODETEXT`（UTF-8 → UTF-16）、图片 `CF_DIB`；失败如实报错，不假装成功
- 命令表新增 `Copy` / `SelectAll` / `OpenSearch`（均非全局，让位给文本输入）
- 线程与队列：文本抽取与检索全部走渲染工作线程（UI 线程零 `fz_*`）；辅助请求走**独立 FIFO 队列**，
  不与 open/close 的单命令槽共用（否则一次悬停就能覆盖掉"待打开的文档"）

## 三轮实测反馈与修复

1. **ADR-069（实现轮）**：坐标空间、线程归属、辅助队列、选区冻结、增量检索。
2. **ADR-070（第一轮反馈修复）**：六条反馈，四条定位到接线处：
   - 光标移出文字后不复原（"整页都是 I 型"，无文字文档反而正常）→ `char_index_at` 的
     "取最近一行/最近一个字符"**没有距离上限** → 命中测试分"悬停严格 / 拖拽吸附"两档
   - `Ctrl+F` 只唤侧栏、不切分栏 → `TabBar` 自带选中态，须一次性 `SetSelected`
   - 侧栏标题栏落在顶栏唤出带里、点不准 → 侧栏区**冻结**顶栏状态
   - 搜索"搜不到东西" → 端到端核查证明 `document` / `render` 通道正常（新增 `render_search_test` +
     `doc_test` 的**自洽检索**断言），实际卡在**触发路径** → 补「搜索」按钮 + 空关键字提示
   - 另两条（复制文本/图片/链接、链接跳转）经确认正常，未改动
3. **ADR-071（第二轮反馈修复）**：
   - 搜索"没用"的真实原因 = 用户**没按到「搜索」按钮** → 改为**停手即搜**（输入防抖 0.4s）
   - 搜索没有取消（只能"删掉关键字再按一次搜索"）→ 新增「停止」按钮 + `Renderer::stop_search()`，
     与 `cancel_search()` 的"作废"语义分开（停止**保留**进度与已找到的命中）
   - 公式复制"不完善" → 定性为**预期边界**（无文本层 / 字体缺 `ToUnicode` / 阅读顺序），
     不投入改动，写入 [架构设计 §10.6](../../02-架构设计.md)

  移出文字立刻变回箭头（含修复轮补测的 ⑥⑦）、放大后中键拖拽仍能平移

  收起侧栏后按 `Ctrl+F` 仍一步到位、手动切到别的分栏后不会被弹回

## 未做 / 已知限制

- 选区**限单页**（跨页选择需要"页序 + 页内偏移"的复合定位与跨页高亮，收益远小于代价）。
- **不做 OCR**：纯扫描件与矢量公式不可选、搜不到（见 [架构设计 §10.6](../../02-架构设计.md)）。
- 复制**尚未**与 `DocumentInfo::can_copy` 联动：声明"禁复制"的加密文档目前仍可复制。
- 文本布局按需抽取（只请求鼠标所在那一页），首次悬停有约一帧的 I 型光标延迟。
