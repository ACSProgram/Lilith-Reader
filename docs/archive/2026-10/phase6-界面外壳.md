# Phase 6 — 界面外壳与美化（✅ 完成 2026-10-06，✅ 人工验证通过 2026-10-06）

> 本文件记录**当时是什么**，不作为当前实现依据；当前事实见 [02-架构设计](../../02-架构设计.md) §4/§7
> 与 [决策记录](../../03-决策记录.md) ADR-045~050。

## 实施内容（2026-10-05，ADR-045）
- **界面外壳**：顶栏图标按钮（扁平）+ 主菜单（☰）+ 画布右键菜单（`Shift+F10`/菜单键为等价入口）
  + 状态栏只读；命令集中在菜单里，不往工具栏堆按钮
- **设置界面**（界面缩放/主题/顶栏自动隐藏/动效/页面间距/缓存预算，改动即时生效并落盘）
  与「快捷键与帮助」界面；两者默认尺寸按视口钳制后居中
- **明/暗/跟随系统三主题**（反色模式下强制深色，沿用 ADR-043）
- **微动效**：页面首次出现淡入、滚动指示条浮现后渐隐、顶栏自动隐藏（`[ui] Motion` 可整体关闭）
- **图标体系**：`Segoe MDL2 Assets` 合并进 UI 字体 + 启动时逐字形校验 + 度量校正
  （`GlyphMinAdvanceX`/`GlyphOffset.y`）；应用图标进 exe（`src/app/app.rc`）
- 应用层重构（同日收尾，ADR-046）：`main.cpp` 2584 行拆为 `main / platform / session / ui`
  四个 TU + 内部头 `app_internal.h`，删除 8 个死接口与 11 个未用图标字形

## 实施内容（2026-10-06 收尾，ADR-047~050）
- **视图动效**（ADR-047）：缩放插值、滚动平滑、跳页滑行、顶栏滑出/滑入，
  统一用一阶滞后（帧率无关指数趋近），动效只在 app 层、画布保持纯函数
- **UI 字体子集内嵌 + FreeType 装载器**（ADR-048）：Noto Sans SC（OFL）子集 1.04MiB 入 exe，
  源码字符集 ⊆ 子集由自动化断言保证，生僻字回退系统 `msyh.ttc`
- **三段外壳显式布局**（ADR-049）：修掉"子窗口间距把状态栏挤出窗口底部、文字被裁"
- **滚动条改为可拖拽**（ADR-050）：几何与命中测试同源

## 人工验证结果（2026-10-06 用户实测，全部通过）
- **6-1 图标与文字对齐、工具栏观感** ✅：图标光学中心与相邻文字齐平；顶栏按钮默认无灰底块，
  悬停才有柔和底色；菜单项行高一致、悬停高亮连续；无 "?" 豆腐块
  - 维护备注：若某台机器图标整体略微偏移，只需调 `src/app/app_internal.h` 的
    `kIconGlyphOffsetY`（正值 = 下移；改动后与 `src/app/platform.cpp` 的 `kIconGlyphs`
    校验范围保持一致），无需改其它代码。ADR-048 换字体后该值无需调整
    （两个字体的归一化 ascent 几乎相同）。
- **6-2 命令可达性与右键菜单** ✅：主菜单与画布右键菜单内容一致、都能打开并执行；
  缩放/列数/对开/旋转/配色的勾选状态与实际一致
- **6-3 设置界面** ✅：各项即时生效；底栏「恢复默认值/关闭」始终可见可点；
  重开后设置被记住（`LilithReader.ini` 出现 `[ui]` 段）；「恢复默认值」能一键复原
- **6-4 快捷键与帮助界面** ✅：分组列出全部快捷键，含新增的 `Shift+F10`；窗口可滚动、可关闭
- **6-5 窗口自适应与 DPI** ✅：接近最小尺寸（400×300）时设置/帮助不超出屏幕、底栏可达；
  150%/200% 缩放下文字清晰、控件不错位、图标与文字仍对齐
- **6-6 微动效（可关闭）** ✅：开启时页面淡入、滚动条渐隐、顶栏收起/重现；关闭时全部直切

## 应用层重构回归（R-1~R-4，2026-10-06 用户实测，全部通过）
> 背景：ADR-046 把 `main.cpp` 拆为四个 TU，代码为原样搬移、行为应逐字不变；
> 自动化不覆盖 app 层，故 R-1~R-4 必须人工确认一遍。
- **R-1 打开与阅读主路径** ✅：命令行/拖放/菜单 `Ctrl+O` 三种入口都能打开；
  滚动、`Ctrl+滚轮` 缩放、方向键翻页、`G` 跳页与重构前一致
- **R-2 外壳与命令** ✅：两处菜单内容一致、勾选态正确；侧栏三标签可用；
  设置改动即时生效并落盘；帮助可关
- **R-3 视图变换与阅读状态** ✅：旋转不形变、配色整套 chrome 同步转暗、书签与阅读位置被记住
- **R-4 加密与窗口态** ✅：密码框行为与重构前一致（输错不闪烁、正确后能读到内容）；
  窗口位置/尺寸/最大化被记住
