# Phase 7 发布打包（2026-10-06）

> 归档：本文件记录 2026-10-06 这一轮"发布打包"的实施过程、根因分析与验证结论。
> **当前事实**以 [02-架构设计](../../02-架构设计.md) §8 与 [ADR-051~053](../../03-决策记录.md) 为准；
> 本文件只记录"当时发生了什么"。

## 1. 范围

Phase 7 的「发布打包」条目：版本资源（Phase 6 已提前落地）、应用图标帧集、
文件类型关联图标、Inno Setup 安装包（每用户安装 / 就地升级 / 关联勾选页 / 卸载数据询问）。

## 2. 触发的问题（人工反馈原文要点）

1. 文件图标**发糊**，且外围有**一圈灰色边缘**；反复强调要解决 **DPI 缩放**问题。
2. 安装器"**乱糟糟的**、像玩具"：卸载时问"是否保留数据"不自然；已安装时打开安装程序，
   先说数据可保留，随后**卸载环节又机械性弹一次**；**不会自动定位到原安装位置**。
3. 图标在 Explorer 里**选中（高亮）时露出白底**。

## 3. 根因与修复

### 3.1 图标发糊 + 灰边：ICO 里其实只有一帧

**先取原始数据再推理**（不猜"可能是缩放算法不好"）：解析 `installer/icons/*.ico` 的目录结构，
发现每个文件**只有 1 帧，且是 16×16**。Explorer 拿到 48px 槽位时只能把 16px 放大 ——
模糊，且深灰描边被拉成一圈灰边。

根因在 Pillow：`IcoImagePlugin._save` 会跳过所有"目标尺寸 > 基准图尺寸"的槽位，
而原脚本把 **16px 帧**当基准图传给 `save()`，于是 20/24/…/256 全被 `continue` 掉。

修复：以 256 为基准图 + `append_images`；帧集扩到 17 帧覆盖非整数缩放率；
改为"超采样原生绘制 + 按尺寸分级简化"；色带统一裁到纸面轮廓（消除"色块溢出"）。
详见 [ADR-051](../../03-决策记录.md)。

### 3.2 安装器：三条症状同一个根

"问两次数据"与"不记目录"来自同一条链路：`InitializeSetup` 里"检测到旧版 →
静默调用旧卸载器"。旧卸载器自己会弹"是否删除阅读数据"，于是同一次操作问了两次；
它同时删掉了卸载注册表项，Inno 随后读不到 `InstallLocation`，自然记不住原目录。

修复：去掉整段"先卸载旧版"，改为 Inno 原生就地覆盖升级；升级检测只读不写；
卸载数据询问收敛为一次（任务对话框、默认保留、静默一律保留）；运行中检测交回
`CloseApplications`（Windows 重启管理器），删掉"改名试探文件占用"的偏方。
详见 [ADR-053](../../03-决策记录.md)。

### 3.3 安装位置：装在 Program Files 下数据写不进去

`DefaultDirName={autopf}\Lilith Reader` 配默认管理员安装 → 装到 `C:\Program Files\Lilith Reader`。
但程序把 `LilithReader.ini`（`WritePrivateProfileStringW`）与 `reader_state.bin`（`CreateFileW`）
写在 **exe 同目录**，两处都**不检查返回值**：x64 进程没有 UAC 文件虚拟化，普通权限写入失败
→ **设置与阅读进度静默不落盘**。同理，关联写 HKCU 在提权安装时会落到管理员账户下。

修复：改为每用户安装（`PrivilegesRequired=lowest`），装到 `%LOCALAPPDATA%\Programs\Lilith Reader`。
详见 [ADR-052](../../03-决策记录.md)。

### 3.4 选中时露出白底：纸面填充铺满整块画布

纸面是"整块画布填白/填渐变"，没有裁到页面轮廓 —— 图标四角 `alpha=255`，
Explorer 选中（蓝色高亮）时就露出一个白方块。

修复：绘制末尾统一 `putalpha(multiply(alpha, page_mask))` 裁到轮廓；
裁掉的是"纸以外"的部分，**纸面本身仍为实心**（不做成空心）。
并把"四角必须透明"写进 `assets/check_icons.py` 的断言防回归。

## 5. 自动化防线（本轮新增）

- `assets/check_icons.py`（接入 `tests/run_tests.ps1`）：断言每个 `.ico` 的帧集完整、
  每帧位图的**真实解码尺寸**与目录项一致、帧非全透明、**四角透明**（防"选中露白底"回归）。
  当前 824 项断言。
- 安装脚本**编译期强校验** `MyAppVersion` 等于 `bin\Release\LilithReader.exe` 的版本资源，
  两处版本不会各自漂移。
