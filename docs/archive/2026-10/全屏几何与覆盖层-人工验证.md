## 16-8 全屏切换布局与阅读位置（普通/最大化）

- **背景**：根 README 长期挂着「最大化状态下退出全屏有一次可见抖动」，ADR-057/058/060 三条
  路均未根治；同时 fit-width 画布的 `zoom` 随视口宽高变化，全屏进出会把同一阅读位置映射到
  另一段文档。本批把窗口几何提交、画布锚定、栏的显隐三件事一起收口（ADR-095~097）。
- **做什么**（与原判据一致）：打开长文档跳到中段（约第 73 页），分别在普通窗口与最大化窗口
  各做一次进入/退出全屏；全屏时把鼠标移到窗口底端再移开；阅读态开着「顶栏自动隐藏」时把鼠标
  移到窗口顶端再移开（画布上方、以及开着侧栏时的侧栏区各试一次）；最后在最大化状态点击取消
  最大化。
- **实测与判定**：**全部通过**（2026-10-07，用户实测报告）。逐条：
  1. 页码不跳段，切换前后视口中心附近仍是同一阅读内容 —— 视口中心锚定生效。
  2. 全屏默认不显示底栏；鼠标靠近底端时底栏**滑入 + 淡入**（约 0.16s）覆盖弹出、移开滑出，
     全程不挤动页面、页码文字不闪。
  3. 顶栏滑入/滑出时**画布不动**（页面不重排、无缩放"呼吸"）；顶栏压在画布之上且按钮**点得中**
     （含滑出动画进行到一半时）。
  4. 开着侧栏时顶栏仍把侧栏整体推下去，不遮住分栏标题。
  5. 页面尺寸只在进入/退出全屏那一次随新视口变化；**不出现**窗口消失、缩小后再归位，也没有
     DWM 过渡动画造成的整窗闪烁 —— 即原「最大化态退出全屏抖动」**已不再复现**。
  6. 取消最大化后恢复到进入全屏前的普通窗口大小（`rcNormalPosition` 未被全屏期间的显式工作区
     几何改写）。
  7. 补充项：设置里关掉「动效」后底栏弹出**直接出现/消失**；关掉「顶栏自动隐藏」后顶栏恢复
     **占位**（画布下移一个顶栏高，顶栏不遮页面顶部）。
- **可复用结论（已写入事实文档）**：
  - 当前实现与各段几何的关系见 [架构设计 §7](../../02-架构设计.md)（覆盖层、绘制顺序即 z 序、
    `canvas_h` 与 `body_h` 的分工）；全屏切换的 Win32 提交顺序见 §7.1。
  - 画布视口变化保持阅读位置的约束见 §2（`Canvas::set_viewport` / `set_margin_gap`），
    并由 `tests/canvas_test.cpp` 第 17 组断言守卫。
  - 决定本体见 [03-决策记录](../../03-决策记录.md) 的 ADR-095 / ADR-096 / ADR-097。
