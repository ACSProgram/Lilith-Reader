## 实施内容
- 记住阅读位置：键 = 路径+大小+修改时间哈希，存 exe 同目录 `reader_state.bin`，原子写入（ADR-034）
- PDF 目录（outline）侧栏 + 跳转：展平为前序序列，POD 缓冲满足 setjmp 纪律（ADR-035）
- 书签（当前页增删/侧栏跳转）、页面缩略图侧栏（低 DPI，**独立通道不占页缓存预算**）（ADR-037）
- 旋转（0/90/180/270，光栅化阶段完成，画布按宽高互换折算）、双页对开（书籍模式＝2 列 + 封面单独成页）（ADR-036/038）
- 反色/护眼模式：渲染线程逐像素变换，保留 alpha（不用 `fz_invert`/tint 的未定义 RGBA 行为）（ADR-036）
- 加密 PDF：密码输入对话框 + `fz_authenticate_password`；权限位读取（`can_copy`/`can_print`）（ADR-039）
- 输入法关联随文本输入激活切换（落实 ADR-028 的后续约束）（ADR-040）
- 验收（自动化）：`reader_state_test` 43 例、`canvas_test` 新增 27 例对开断言、
  `doc_test` 新增目录/旋转/配色断言（合计 55 例）；Release 编译 0 警告 0 错误

## 人工验证结果（2026-10-06 用户实测，全部通过）
- **5-1 阅读位置记忆** ✅：滚到中后段并调整列数/缩放/旋转/配色后关闭，再次打开回到上次的页，
  视图参数一致；关闭程序再打开同样恢复
- **5-2 目录侧栏 + 跳转** ✅：目录项按层级缩进、文字正确，点击跳到对应页，`O` 可收起
- **5-3 书签** ✅：`B` 增删、侧栏列出、跳转即生效、每行 `×` 都能点中并删除对应书签、重开后仍在
- **5-4 缩略图侧栏** ✅：逐步加载不阻塞主界面，点击跳页，旋转/反色后缩略图随之更新
- **5-5 旋转** ✅：0→90→180→270 循环，内容与版面框同步旋转（90/270 宽高互换）、不形变、不闪白
- **5-6 双页对开（书籍模式）** ✅：封面单独成页且居中，之后 (2,3)、(4,5)… 对开；
  **对开期间直接按列键即切到对应列数并退出对开**，只按 `D` 关闭时恢复进入前的列数
- **5-7 反色 / 护眼** ✅：整篇立即变色，反色为柔化暗色（深灰底浅灰字）且整套 chrome 同步转深色；
  切换时可见页不被清成空白
- **5-8 加密 PDF** ✅：错误密码提示且弹窗不闪烁；正确密码解锁后能读到页面内容；取消/Esc 返回引导页
- **5-9 输入法回归** ✅：阅读态字母/数字快捷键全部生效（不被输入法吞键）；密码框内可输入中文

## 本轮验证暴露并已修复的问题（2026-10-05，ADR-041~044）
- 加密样本解锁后整页空白 → 认证成功后不得再问 `fz_needs_password()`
- 书签 `×` 点不到 → Selectable 显式让出按钮宽度
- 反色辣眼、开反色/护眼整页闪白 → 柔化暗色映射 + 整窗深色 + 保留旧纹理原地换入
- 密码框错误密码时闪烁 → 认证期间保持弹窗打开
- 对开与列数同层级互斥（`canvas_test` 已钉死映射）
