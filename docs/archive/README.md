# 归档索引

`archive/` 只保存**已完成**阶段的实施细节、事故记录、实测数据与已通过的人工验证清单。
归档文件记录"当时是什么"，不作为当前实现依据——当前事实以 [02-架构设计](../02-架构设计.md)
与各模块文件头注释为准。

写入规则：每个阶段/每轮调试收尾时，把过程记录与已通过的验证清单移入
`archive/YYYY-MM/`（文件名按内容命名，日期写在文件标题里），并在下方索引登记。
可复用的结论先改写成当前约束写入事实文档，再在日志里链接过去，避免同一份内容出现在两处。
