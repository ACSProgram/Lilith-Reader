## 待执行

### 4-5 失败重试（构造性）

- **做什么**：用 `tests/samples/` 里的**损坏样本**（截断 / 随机字节 / 空 PDF）打开，
  或人为改坏 PDF 某页的内容流，触发单页渲染失败。
- **不要**再用 A0 超大面触发：ADR-073 的分块渲染把大页切成 tile 逐块渲染，内存峰值受控，
  超大图只会慢、不会失败 —— 2026-10-07 实测 17552×15391（226 MB）的图可正常渲染，仅耗时十余秒。
- **算通过**：**从未成功渲染过**的失败页显示「渲染失败 · 点击重试」占位，点击后重新尝试，
  成功后占位消失；**曾成功渲染过**的页重渲失败时**保留旧图**（不闪白、不显示占位），
  继续缩放（倍率变化）会重新尝试。两路都不出现无限重试。

### 12-9 EPUB 与选区持久性（缺样本）

- **做什么**：① 用一份**多页** EPUB 重复选择与复制；② 在某页选好一段文字后，把鼠标移到**另一页**
  （不要点击），再回到右键菜单点「复制」。
- **算通过**：① EPUB 下同样能选择并复制；② 选区高亮**仍然显示**，且复制出的是**原来那一段**。
- **样本说明**：`tests/samples/real.epub` 只有 1 章、正文 5 个字，做不了跨页；
  需要多章节、每章有实质正文的 EPUB（用户自备）。

### 15-4 帧异常自愈（可选，需临时注入）

- **做什么**：Debug 构建下临时在某个绘制分支里 `throw std::runtime_error("test")`。
- **算通过**：进程不退出，日志出现 `frame aborted: test`，窗口保留上一帧画面（不闪黑）；
  下一帧起恢复正常绘制；Debug 日志里**没有** `IMGUI STACK LEAK`。

### 16-1 失败提示：落盘失败（构造，ADR-089）

- **做什么**：把 `bin\Release\reader_state.bin`（或 exe 所在目录）设为只读，启动后翻页/加书签触发落盘；
  随后去掉只读，再触发一次保存。
- **算通过**：状态栏出现告警色文案「阅读数据保存失败」，且**首次**出现时有一次 toast；
  日志出现 `persist` 的写失败记录（含路径）；恢复可写、下一次写盘成功后告警**消失**。

### 16-3 MOBI HUFF/CDIC 真样本（部分已通过）

- **已通过**：真实 `.mobi` 可正常打开与阅读（覆盖未压缩 / PalmDOC 两条支持路径）。
- **待执行**：用一份 **HUFF/CDIC 压缩**的真实 `.mobi`（Kindle 导出常见）打开。
- **算通过**：提示**「暂不支持的格式」**，而不是"文件已损坏"。
- **说明**：HUFF/CDIC 的边界已由 `doc_test` 自动断言；本项只补真实世界样本的观感确认。

### 16-4 UI 层交互竞态（真实窗口）

- **做什么**：真实窗口下连做三组：① 快速连续打开 / 关闭 / 切换文档（含加密文档与密码框，
  认证在途时就切换）；② 检索进行中切换文档、复制文本/图片、切列/旋转/缩放；
  ③ 反复快速开关同一文档 ≥20 次。
- **算通过**：无崩溃、无卡死；标题/页码/内容始终是**当前**文档的（无旧结果串台）；
  日志无异常与 `frame aborted`。
- **背景**：app 层不进入 `run_tests.ps1`（Win32/D3D/ImGui 直连，无头测试成本高）；
  渲染边界的同类竞态已由 `render_search_test` / `render_fault_test` 覆盖，本项补真实窗口路径。
