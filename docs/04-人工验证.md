# 人工验证清单

> 项目纪律：开发过程不实际运行软件做测试（编译/自动化测试除外）。
> 本文档只保留**待执行**的验证项；已通过的整节移入 `docs/history/` 对应阶段文件。

准备：Release 编译产物 `bin\Release\LilithReader.exe`。
下面用到的样本文件可临时构造，验证完可删除。

**已全部自动化**：合法格式、改名放行、归档冒充拒绝、加密识别、损坏/截断/垃圾头，

### 五、已知限制（不属于缺陷，无需修复）

- 页面**渲染**与画布（缩放/滚动/多列）已在 Phase 3 接入，见下节。
- 加密文档只能识别并提示，密码输入框在 Phase 5。
- 阅读位置记忆、书签、目录跳转在 Phase 5。
- UI 字体仍为系统微软雅黑（子集化内嵌在 Phase 6）。
- Windows Defender 误报问题见 README「已知问题」，与 Phase 2 无关。

## Phase 3 待验证：自研画布

准备：Release 编译产物 `bin\Release\LilithReader.exe`；一个多页 PDF（建议另备一个
**1000 页**的 PDF 测性能）。按 `F3` 可开调试浮层观察 FPS / 帧时间 / zoom / 可见范围。

> **布局数学已全部自动化**：fit-width 派生、固定缩放居中、内容尺寸、滚动钳制、
> 以鼠标为锚的缩放定点不变性、命中测试、可见范围、列切换锚定、非均匀页尺寸、
> 缩放钳制、空文档，共 **61 例断言**（`tests/canvas_test.cpp`，`tests\run_tests.ps1` 可复验）。
> 下表只保留**必须人眼/手感**的项目。

### 一、渲染与滚动（3a）

| # | 操作 | 通过判据 |
|---|---|---|
| 3-1 | 拖入多页 PDF | 立即进入阅读态，首页按 fit-width **铺满窗口宽度**；无白屏、无错位 |
| 3-2 | 滚轮上下滚动 | 滚动跟手；滚到顶部/底部**不越界**（不出现滚过头的空白） |
| 3-3 | ↑↓ / PgUp PgDn / Home / End | 小步滚动 / 整屏滚动 / 到首页 / 到末页，行为符合直觉 |
| 3-4 | ←→ | 单列时上/下页；多列时上/下一行 |
| 3-5 | 左键按住拖动 | 内容随鼠标平移；到边界停住 |

### 二、缩放（3b）

| # | 操作 | 通过判据 |
|---|---|---|
| 3-6 | Ctrl+滚轮在页面某处缩放 | **光标下的内容保持不动**（以鼠标为不动点）；缩放跟手 |
| 3-7 | 连续快速缩放后停手 | 过程中**无闪白**；停手约 150ms 后画面变**清晰**（高清纹理换入） |
| 3-8 | 放大到高倍率后拖动 | 文字清晰（按新倍率重渲染），平移正常 |
| 3-9 | 按 +/− / Ctrl+0 / F | 以视口中心缩放 / 回到 fit-width；F 与 Ctrl+0 行为一致 |
