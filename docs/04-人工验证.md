## Phase 4 渲染调度与纹理管理（余项）

> 自动化已覆盖的部分（无需人工）：预算钳制、LRU 逐出选择、失败重试策略
> —— `tests/page_cache_test.cpp`，32 例断言。

### 4-2 无句柄 / GDI / USER 对象泄漏
- **做什么**：打开文档，滚动过程中在任务管理器「详细信息」页启用「句柄」「GDI 对象」「USER 对象」
  列持续观察；再反复打开/关闭同一文档 20 次。
- **算通过**：三列数值**平稳、不持续单调上升**；反复开关文档后回落到与初始接近的水平。

### 4-5 失败重试（构造性）
- **做什么**：用超大幅面（A0 海报类）或人为损坏样本触发单页渲染失败。
- **算通过**：**从未成功渲染过**的失败页显示「渲染失败 · 点击重试」占位，点击后重新尝试，
  成功后占位消失；**曾成功渲染过**的页重渲失败时**保留旧图**（不闪白、不显示占位），
  继续缩放（倍率变化）会重新尝试。两路都不出现无限重试。

## 第六阶段收尾（2026-10-06 建立，待执行）

> 背景：本轮针对人工验证反馈的三条问题（状态栏贴边、滚动条拖不动、看不到动效）做了修复，
> 并补齐 Phase 6 最后两项未完成工作（字体子集内嵌、缩放/滚动平滑插值），对应 ADR-047~050。
> 改动集中在 `src/app/ui.cpp`（布局/滚动条/动效）、`src/app/session.cpp`（动效层）、
> `src/app/platform.cpp`（字体装载）。**app 层无自动化覆盖**，故下列项必须人工执行。

### 7-1 三段布局与状态栏留白（反馈 1）
- **做什么**：打开任一文档，看底部状态栏「第 N / M 页」与右侧格式文字；
  再反复拖动窗口边缘改尺寸、并把窗口拖到 150% 缩放显示器上。
- **算通过**：状态栏文字**上下留白均衡、下缘不贴窗口边、不被裁**；
  任何窗口尺寸下三段（顶栏/画布/状态栏）都恰好铺满客户区，底部不出现被裁的条或空白带。

### 7-2 视图动效：缩放与滚动（反馈 3）
- **做什么**：`Ctrl+滚轮` 连续缩放、按 `+`/`-`、菜单里点缩放档位与「适合宽度」；
  再用滚轮、方向键、`PgUp/PgDn` 滚动；然后打开设置关掉「界面动效」，重复一遍。
- **算通过**：开动效时缩放是**平滑过渡**（不是台阶式跳变）、且鼠标指向的位置保持不动；
  滚动平滑无顿挫但**跟手**（不是"飘"）；「适合宽度」也是平滑过渡到 fit 倍率。
  关动效时以上全部变为**立即生效**（等价于本轮之前的行为）。
- **备注**：F3 浮层的 `motion: pending … zoom->… anim …` 读数可直接确认动效是否在跑。

### 7-3 视图动效：跳页滑行与顶栏滑动
- **做什么**：用 `G` 跳页、点目录/书签/缩略图跳转、按 `←`/`→` 翻页；再把鼠标移开窗口顶部等顶栏自动收起，然后移回顶部。
- **算通过**：跳页是**滑行**过去的（不是瞬间跳），滑行结束后**页码与目标页一致**
  （特别是跳到靠近文档末尾、目标行无法贴到视口顶部的那些页）；
  顶栏收起/重现是**滑上去/滑下来**，不是整块闪现或消失。

### 7-4 滚动条拖拽（反馈 2）
- **做什么**：把鼠标移到画布右侧滚动条上，按住滑块上下拖；点轨道空白处；悬停不点；
  拖到最顶端与最底端；拖动过程中留意页面是否跟着鼠标"平移"。
- **算通过**：拖动滑块时页面**跟随滚动**（不是页面被拖动平移）；松手后立即停在当前位置（不回弹、不继续飘）；
  点轨道空白处滑块跳到该处并转为拖拽；悬停时滑块变宽并有高亮；拖到两端能到达首页/末页。
- **备注**：F3 浮层的 `bar drag` 读数在拖拽期间应为 1。

### 7-5 UI 字体子集观感与 fallback
- **做什么**：整体浏览界面（顶栏/菜单/设置/按键/状态栏/引导页）的文字观感；
  在 150% 缩放下再看一遍图标与文字的对齐；打开一个**文件名含生僻字**或**目录标题含生僻字**的文档。
- **算通过**：中文显示正常、无豆腐块；字号/字重/行距观感可接受（与之前的微软雅黑相比允许有差异，
  但不能出现明显偏瘦/偏挤/基线错位）；图标与汉字仍对齐；生僻字由系统字体 fallback 正常显示。
- **备注**：若某台机器缺 `msyh.ttc`，界面自述文字仍完整（子集已覆盖），只是生僻字会显示为缺字框。

> 背景：本轮加入**按键自定义**（ADR-054）并补齐动效遗漏（侧栏滑入/滑出、设置窗口开合，
> ADR-055），随后按体感反馈把设置窗口动画改为**缩放+淡入淡出**（ADR-056）与**定时补间 + 缓出**
> （ADR-061）、补上**弹出对话框动效**（ADR-059）、三轮修复**全屏切换闪烁**
> （ADR-057 → ADR-058 → ADR-060），并修掉**弹窗关闭闪帧**与**最小化闪帧**（ADR-061）。
> 改动集中在 `src/app/{ui,session,platform,main}.cpp` 与 `app_internal.h`。**app 层无自动化覆盖**，
> 下列项必须人工执行。
>
> 已通过项（9-3 设置窗口开合动画、9-6 弹出对话框开合动效、9-7 最小化不闪帧）已移入
> [archive/2026-10/交互与动效优化.md](archive/2026-10/交互与动效优化.md)；
> 9-4 为**部分通过**（普通窗口已消除，最大化态抖动列为已知缺陷），连同 9-1/9-2/9-5 留在下方。

### 9-1 按键自定义（设置 → 按键分栏）
- **做什么**：`Ctrl+,` 或 `F1` 打开设置，切到「按键」分栏；点某条命令的键槽进入捕获、按一个组合键；
  再试：给不同命令绑同一个键、右键清除某个键槽、点「恢复默认」；改完**重启程序**再看该分栏。
- **算通过**：捕获时按下的组合被如实记入键槽并**立即生效**（改完不用重启即可用新键）；冲突有提示；
  右键可清除；恢复默认能回到出厂键位；重启后改过的键仍在（落盘到 `LilithReader.ini` 的 `[keys]` 节）。
- **备注**：菜单/右键菜单里显示的快捷键应随改键同步（取当前绑定，不是写死字符串）。

### 9-2 侧栏滑入 / 滑出
- **做什么**：按 `O`（或点顶栏「侧栏」、菜单项）开、关侧栏，来回几次；
  然后打开设置关掉「界面动效」，再开、关一次。
- **算通过**：开动效时侧栏是**从左侧滑出/滑回**（宽度渐变），滑出过程中面板内容**不重排**（文字不跳行）；
  关动效时立即出现/消失、无中间态。

### 9-4 全屏切换不再闪烁（`F11` / `Esc`）——部分通过
- **做什么**：**三种起始状态各做一遍**，每种都来回切换多次：
  ① 普通尺寸窗口；② **最大化**窗口；③ 把窗口拖到副显示器后再做 ①②。
  进入用 `F11`，退出用 `F11` 与 `Esc` 各试。
- **已通过的部分**：**普通尺寸**进出全屏干净、无单帧闪烁；退出后窗口回到进入前的状态与位置
  （进入前是最大化就回到最大化，且"还原"回到最大化前的尺寸）。
- **已知缺陷（不阻塞，无需再单独排期）**：**最大化**状态下退出全屏仍有"往左上缩一下再归位"的抖动。
  已试过命令时机（ADR-060）、Win32 顺序（ADR-058）、swapchain 时机（ADR-057）三条路均未根治，
  记入根 README「已知问题」。**若日后顺手复现，请记录**：进入还是退出、单屏还是跨屏、
  进入全屏前窗口是普通还是最大化、系统"最小化/最大化时动画"开关是否打开。
- **备注**：本轮把全屏切换挪到**帧首**执行（ADR-060），普通窗口的闪烁由此消除。

### 9-5 `Esc` 语义变更回归
- **做什么**：阅读文档时按 `Esc`；打开设置/跳页/密码框时按 `Esc`；再在引导页（无文档）按 `Esc`。
- **算通过**：阅读态按 `Esc` **不再**关闭文档、也不退出（默认绑定下它切全屏）；有对话框时 `Esc` 关闭
  当前对话框；引导页按 `Esc` 不做任何破坏性动作（不会退出）。关闭文档/退出**只能**走菜单。

## 已知限制（不属于缺陷，无需修复）

- **输入法关联是条件式的**（ADR-028/040）：阅读态脱离输入法（否则吞字母/数字键），
  仅在文本输入激活（密码框等）时临时关联回来。若将来加入需要中文的搜索/批注框，机制已就位。
- 加密文档的**权限位**（`can_copy`/`can_print`）已读取，但当前尚无复制/打印功能，字段先就位供后续置灰。
- **交互不再只靠键盘**（Phase 6）：顶栏图标按钮 + 主菜单 + 画布右键菜单 + 设置/按键界面已就位，
  与快捷键等价；阅读态快捷键**不依赖窗口焦点**、不受输入法干扰（ADR-026/028）的约束仍然生效。
- UI 字体为**内嵌子集**（Noto Sans SC，GB2312 一级 + 源码字符集）+ 系统 `msyh.ttc` 生僻字 fallback
  （ADR-048）。子集不含的字若系统也没有对应字体，会显示缺字框 —— 属预期降级。
- 缩略图侧栏只请求当前页 ±40 页（随当前页扩展），并非整本一次性渲染。
- 视图动效（缩放插值/滚动平滑/跳页滑行/顶栏滑动）由 `[ui] Motion` 统一开关（ADR-047）；
  关闭后所有路径立即生效，不留中间态。
- Windows Defender 误报问题见 README「已知问题」，与本阶段无关。
