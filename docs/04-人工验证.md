## 待执行

### 16-4 UI 层交互竞态（真实窗口）

- **做什么**：真实窗口下连做三组：① 快速连续打开 / 关闭 / 切换文档（含加密文档与密码框，
  认证在途时就切换）；② 检索进行中切换文档、复制文本/图片、切列/旋转/缩放；
  ③ 反复快速开关同一文档 ≥20 次。
- **算通过**：无崩溃、无卡死；标题/页码/内容始终是**当前**文档的（无旧结果串台）；
  日志无异常与 `frame aborted`。
- **背景**：app 层不进入 `run_tests.ps1`（Win32/D3D/ImGui 直连，无头测试成本高）；
  渲染边界的同类竞态已由 `render_search_test` / `render_fault_test` 覆盖，本项补真实窗口路径。

### 17-1 导出对话框与输出选择（导出为图片，ADR-101）

- **做什么**：主菜单「导出为 → PNG 图片…」与快捷键 `Ctrl+E` 各打开一次对话框，确认可设
  范围（当前页 / 全部页 / 自定义）、清晰度（DPI 档位与自定义输入）、质量（仅 JPEG 有滑杆）、
  「应用当前视图」勾选；自定义范围输入越界值时被钳到 `[1, 总页数]`。点「导出」：单页应弹
  **另存为**、多页应弹**选目录**；并分别在这两个对话框里点「取消」。
- **算通过**：两个入口都能打开对话框；PNG 不出现质量栏、JPEG 出现；取消输出选择后
  **不产生任何文件**，程序状态正常（可再次打开对话框重来）；按下 `Esc` 关闭对话框。
- **背景**：app 层不进 `run_tests.ps1`（Win32/ImGui 直连），对话框与模态输出选择的交互只能
  人工确认。document 层的编码写出已自动化（`tests/doc_test.cpp` 的 4 个导出用例）。

### 17-2 导出结果与文件名（导出为图片，ADR-101）

- **做什么**：① 单页导出到自选文件；② 多页（全部页或自定义范围）导出到自选目录；
  ③ 打开一个**文件名或所在目录含中文**的文档后导出；④ 勾选「应用当前视图」，把文档旋转
  90° 并切到深色纸张后导出，再取消勾选对比一次；⑤ 用较高 DPI（如 600）导出 A4 页。
- **算通过**：①②成功，且**多页文件名形如 `<主干>_p0001.png`**（页号补零 4 位、字典序 = 页序）；
  ③中文名 / 中文路径下文件正常生成且可打开；④勾选时导出图含旋转与纸张配色、不勾选时为文档
  原样；⑤成功且分辨率按所选 DPI（若被单边像素上限下调，`logs\` 留有一条 `export scale
  capped` 记录，属预期）。
- **背景**：覆盖"渲染 → 编码 → 宽字符路径写出"整条链路的观感与命名约定（ADR-101）。

### 17-3 导出期间阅读不受影响与取消（导出为图片，ADR-101）

- **做什么**：发起一次大范围 / 高 DPI 导出，导出进行中滚动、缩放、检索；再发起一次并在
  进度提示仍在时点「取消导出」；另一次在导出进行中**打开 / 关闭文档**。
- **算通过**：导出期间滚动与检索**依旧流畅**（不卡顿）；状态栏持续显示 `正在导出 N/M 页…`；
  「取消导出」在当页结束后停止并提示；导出进行中打开 / 关闭文档会**取消在途导出**，无崩溃、
  无错导（不会把旧文档的页导到新文档上）。
- **背景**：验证"每轮至多一页、不抢占渲染/检索"这一取舍的实际观感（ADR-101）。
